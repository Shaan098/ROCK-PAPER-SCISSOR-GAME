# 🎮 Rock Paper Scissors Game  
A simple, interactive, and visually appealing **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.  
This project recreates the classic hand game where the player competes against the computer with real-time results, animations, scoring, and autoplay features.

-------


## 🚀 Features

### ✔ Play Against Computer  
Choose **Rock**, **Paper**, or **Scissors** and instantly see the result.

### ✔ Random Computer Move  
The computer uses `Math.random()` to choose between Rock, Paper, and Scissors.

### ✔ Live Scoreboard  
Tracks:  
- 🟢 Wins  
- 🔴 Losses  
- 🟡 Ties  
### ✔ Auto-Play Mode  
The game automatically plays every second using `setInterval()`:
- Random moves for player and computer  
- Score updates continuously  
- Press again to stop autoplay  
### ✔ Reset Button  
Clear the entire score and start again anytime.

### ✔ Smooth Animations  
The chosen move highlights with scaling and shadow effects.

### ✔ Responsive & Clean UI  
Styled using CSS with:  
- Gradient background  
- Circular icons  
- Hover effects  
- Shadows  
- Modern layout

## 📘 How It Works

1. Player clicks an option  
2. JavaScript generates a random computer move  
3. Logic compares both moves  
4. Result + score updates automatically  
5. Auto-Play continuously runs rounds until stopped  

Rules:
- Rock beats Scissors  
- Paper beats Rock  
- Scissors beats Paper  
- Same choice → Tie
